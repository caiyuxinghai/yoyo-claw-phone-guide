# YOYO Claw 在荣耀手机上的使用与排障记录

这份独立实测记录整理了 YOYO Claw（YOYO Claw PAD）在一台荣耀手机上的启动拦截、模型配置、“完全访问”菜单显示问题，以及手机 Linux 环境运行 Kali 的可行路径。

## 实测结果

- 原版 YOYO Claw 20.0.0.10 曾因缺少 `com.hihonor.pcenginewps` 而卡在“资源下载”弹窗。测试时，Linux 实验室 `com.hihonor.pcengine` 已满足最低版本，PC 应用专区也满足门槛；荣耀应用市场对缺失组件没有提供下载。
- 在该设备上，使用一个本地制作的**非官方空兼容占位包**通过了启动版本检查。原版 YOYO 随后进入主界面，并完成了模型文字回复和 shell 工具调用。仓库现在附上该 8 KB 诊断 APK；它不包含荣耀引擎代码，也没有权限，不能补上依赖真实 PC 引擎的功能。它与荣耀组件使用相同包名，可能阻止正版组件直接安装，详见[使用方法](docs/使用方法.md)。
- YOYO 设置中的“完全访问”选项被前端菜单裁切。临时调整 Android 显示密度后成功开启；恢复默认密度后设置仍保留。该模式是 YOYO Agent 的工具审批设置，不会取得 Android root 权限。
- 原版已通过火山引擎 Agent Plan 的 OpenAI 兼容接口完成文字回复与工具调用。示例配置和安全注意事项见[使用方法](docs/使用方法.md)。密钥没有保存在仓库中。
- 荣耀“Linux 实验室”运行于 `proot` 容器中，不是可以直接启动 Kali ISO 的完整虚拟机。建议研究 Android 侧独立运行 Kali NetHunter Rootless；本次没有在该手机上安装 Kali。
