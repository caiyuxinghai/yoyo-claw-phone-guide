# 隐私与安全说明

- **不要公开 API Key。** 密钥仅应保存在应用的凭据设置中。发 issue、录屏或截图前检查是否出现完整密钥、请求头、二维码或账户信息。
- **不要公开设备序列号、IMEI、账号标识、通知、聊天内容或本机路径。** 本项目不包含原始设备截图、ADB 输出、荣耀原版安装包或用户目录。
- **小心“完全访问”。** 它扩大 Agent 工具的操作范围，但不等同于 Android root。对来源不明的模型和提示词不要开放工具执行。
- **执行工具前审阅命令。** shell 工具可能读写文件、访问网络或修改应用数据。使用无副作用的固定字符串命令验证，不要把密码、密钥和私人文件放进测试请求。
- **优先使用荣耀官方组件。** 仓库附带的空占位包只是特定设备上的诊断实验，不实现引擎功能。它会占用荣耀组件的包名，可能阻止正版同名应用安装；只有核实包版本并了解回退方法后才考虑使用。不要把未知来源的同包名 APK 当成荣耀官方软件。
- **荣耀原版 APK 不随仓库分发。** YOYO Claw 和 Linux 实验室 APK 属于荣耀软件；请从荣耀官方渠道获取。
- **注意套餐计费。** 订阅套餐 Base URL 和通用 API Base URL 可能有不同计费规则。以火山引擎控制台当前说明为准。
- **Kali Rootless 权限有限。** 它的容器内 root 身份是 proot 模拟，不是主机 Android root。只在自己拥有或明确授权的目标上使用安全测试工具。

如果在公开历史中意外暴露过有效密钥，应立即在对应服务商控制台撤销并重建，再更新手机中的配置。
