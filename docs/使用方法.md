# YOYO Claw 使用与配置

## 1. 初次启动被“资源下载”拦截

测试设备上的 YOYO Claw 20.0.0.10 会检查三项荣耀组件：

| 组件 | 包名 | 测试时版本/状态 | 应用检查门槛 |
|---|---|---:|---:|
| Linux 实验室 | `com.hihonor.pcengine` | `100002233`（lite） | `100002231` 或更高 |
| PC 应用引擎 | `com.hihonor.pcenginewps` | 未安装 | `100003210` 或更高 |
| PC 应用专区 | `com.hihonor.pczone` | `120702167` | 高于 `120702108` |

本次阻塞原因是第二项缺失。即使安装了 Linux 实验室，也不代表另一个 PC 应用引擎组件已经存在。测试时荣耀应用市场没有提供该组件的下载入口。

**优先办法：** 通过荣耀官方支持渠道确认适用于本机的正版组件及支持机型。不要安装来源不明、只伪造包名或版本号的 APK。

本次诊断曾用一个本地空占位包让版本检查通过，之后验证了原版应用主界面、模型回复和 shell 工具调用。该 APK 放在 [`assets/yoyo-pcenginewps-placeholder.apk`](../assets/yoyo-pcenginewps-placeholder.apk)，元数据如下：

| 字段 | 值 |
|---|---|
| 包名 | `com.hihonor.pcenginewps`（与荣耀官方组件同名） |
| versionCode | `100003210` |
| versionName | `codex-compat-placeholder-1` |
| 大小 | 8,478 bytes |
| SHA-256 | `FB79715652AFEBEB422FAD68A9B0B9E994CBB345AC1101E4B31086A57C4D9389` |

静态检查显示该包没有权限、可执行代码、Activity、Service 或 Provider。它只是本次实验的版本检查占位物，不是荣耀修复包，也不含引擎能力；依赖 `pcenginewps` 的窗口控制等功能仍可能失败。

**重要：** 同包名会与正版 `pcenginewps` 冲突，签名也不同。若设备已经安装正版组件，不要安装此文件；否则可能要先卸载占位包，正版才能安装。仅当通过 Android 包信息确认 `versionName` 精确为 `codex-compat-placeholder-1` 时，才可用 ADB 执行 `adb uninstall com.hihonor.pcenginewps` 回退。不要误卸载荣耀官方版本。普通用户优先向荣耀获取适配本机的正式组件。

仓库只附本次自制的兼容占位 APK，不包含荣耀原版 YOYO 或 Linux 实验室 APK；后两者是荣耀软件，需从荣耀官方渠道获取。

## 2. 配置火山引擎 Agent Plan

在 YOYO Claw 中打开“设置 → 模型供应商 → 添加模型供应商”，按照订阅控制台当前显示的协议和地址填写：

| 设置项 | 本次成功配置 |
|---|---|
| 协议 | OpenAI 兼容 |
| Base URL | `https://ark.cn-beijing.volces.com/api/plan/v3` |
| 模型 ID | `glm-5.3-flash` |
| API Key | 在设备上输入自己的有效套餐密钥；不要写入脚本、截图、日志或公开仓库 |

保存并通过接口检查后，在聊天模型列表中选择刚添加的模型。本次原版 YOYO 的自定义模型完成了文字回复和受控 shell 命令测试。

火山引擎订阅页面对套餐专用地址有说明；不要随意把 Base URL 改成通用 `/api/v3` 地址，以免走到其他计费入口。实际套餐、限额和费用以账户控制台为准。

本次也试过 Anthropic 兼容路径 `/api/plan`：工具动作有返回，但最后的文字回复为空。切回上述 OpenAI 兼容配置后，文字与工具回复均正常。该结果只代表本次应用、模型和套餐组合。

## 3. 将屏幕外的“完全访问”选项显示出来

问题出在 YOYO 前端缩放后的弹出菜单被屏幕边缘裁切。以下临时办法只在本次设备上验证过：

1. 连接 ADB，先运行 `adb shell wm density`，记下当前 density override；若没有 override，记录物理密度。
2. 临时运行 `adb shell wm density 320`，回到 YOYO 聊天页打开审批模式菜单。
3. 选择“完全访问”并确认系统弹窗。
4. 若开始前没有 override，运行 `adb shell wm density reset` 恢复默认值；若原本已有 override，则恢复之前记录的数值。
5. 再检查 `adb shell wm density`，确认显示设置已恢复。

320 是本次设备的临时值，不保证适合其他手机。改变 density 会影响全系统布局。完成设置后要恢复原值；如果不熟悉 ADB，可请荣耀客服协助处理菜单裁切问题。

“完全访问”表示 YOYO Agent 在应用内不再逐项等待审批。它不会给 Android root 权限，但会增加 Agent 工具操作的影响范围。只把它用于可信模型和你能检查的任务；执行可能读写文件、联网或改动设置的命令前，先检查命令内容。

## 4. 验证及回退

先用只输出固定字符串的无副作用命令验证工具通路，例如：

```sh
printf YOYO_TOOL_OK
```

不要用包含个人文件、令牌或系统配置的命令作测试。如果要切回 YOYO 自带模型，直接在聊天模型选择器中改回原模型；删除自定义提供方前先确认是否还被其他对话使用。

若某台设备安装过仓库里的兼容占位包，卸载前必须在 Android 包信息中核对 `com.hihonor.pcenginewps` 的 `versionName` 是否为 `codex-compat-placeholder-1`；不要误卸载荣耀官方同名组件。卸载占位后，资源下载拦截可能重新出现。
